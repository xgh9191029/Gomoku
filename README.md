# ⚪⚫ 五子棋多房间在线对战平台
使用gemini和deepseek许愿完成的项目
基于 Python (`asyncio` + `websockets` + `SQLite`) 与原生前端 (`HTML5 Canvas` + `JavaScript`) 开发的多人在线五子棋对战系统。后端通过 `websockets` 的 HTTP 拦截功能实现了全栈一体化，单文件即可同时托管网页前端和 WebSocket 服务。
---

## 🌟 主要功能特性

1. **多房间与观战系统**：
   - 支持创建自定义 4 位数字房间。
   - 大厅自动过滤并**只显示未满的房间**。
   - 支持通过手动输入已满房间号进行**旁观（观战）**，观战离开不影响正在进行的对局。
2. **完整的用户与账号体系**：
   - 支持账号注册、密码加密存储（PBKDF2-HMAC-SHA256）。
   - 登录状态持久化与 7 天免登录（基于 Token 验证与 Cookie）。
   - **单点登录（多端互踢）**：同一账号在别处登录时，旧连接会自动断开。
   - 账号自主注销功能。
3. **安全防护机制**：
   - **IP 注册限制**：限制同一 IP 地址在 3 天内最多只能注册 50 个账号，有效防止恶意刷号。
4. **丰富的对局交互**：
   - 五子连珠胜负判定。
   - 游戏内实时聊天。
   - 和棋申请与同意/拒绝机制。
   - 新一局申请与换边机制（黑棋获胜后下一局自动交换黑白双方）。
   - 个人胜场、败场及胜率实时统计。

## 📦 环境依赖

本项目仅依赖一个第三方 Python 库（其余均为 Python 标准库）：
* **`websockets`** (用于处理 WebSocket 连接与 HTTP 静态文件托管)

可以通过以下命令安装：
```bash
pip install websockets
```

---

## 🚀 快速启动指南

1. **准备文件**：确保 `main.py` 和 `index.html` 放在**同一个文件夹**内。
2. **运行服务**：
   ```bash
   python main.py
   ```
3. **访问游戏**：
   - 本机访问：打开浏览器输入 `http://localhost:8765`
   - 局域网访问：使用局域网内的其他设备访问 `http://<你的电脑局域网IP>:8765`
